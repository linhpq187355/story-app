## Tech Stack

- JavaScript
- Vite
- Tailwind CSS

- Axios

---

## General Rules

- Always reuse existing components.
- Never duplicate UI components.
- Keep components small and reusable.
- One component should have only one responsibility.
- Never hardcode colors or spacing.

## Responsive Strategy

Desktop First

Primary target:
- 1920px
- 1440px
- 1366px
- 1280px

Secondary target:
- Tablet
- Mobile

Every page must be fully functional on desktop.

Mobile layout is adapted from desktop, not the opposite.

## Before Creating Anything

Always search existing components.

If a component already exists

Reuse it.

If 80% similar

Refactor instead of creating a new one.
